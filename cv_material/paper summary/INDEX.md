## How to use for a new CV version

1. Identify the target internship's focus area (mobile systems / VLM / embodied AI / generative AI / FL).
2. Open the relevant summaries and copy the bullet length that fits available space (short / medium / long).
3. If a new ordering or emphasis is needed, the "Notable details" section flags each paper's pitch-worthy angles.
4. Update this index when a new paper is added or a status changes (under review → accepted).
