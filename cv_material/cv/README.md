# CV organization

- `public_sources/`: editable sources and PDFs for reviewed public CV versions.
- `archive/`: older general CV versions.
- `applications/`: role-specific and visa CVs, with their supporting descriptions.
- `templates/`: reference CV templates.
- `private/current/`: latest local CV source and PDF.
- `private/history/`: previous local CV snapshots.

The `private/` directory and `../papers_under_submission/` are Git-ignored. All of `cv_material/` is excluded from the Jekyll site. Keep unpublished content in those local directories.

Published PDF copies stay in `../../pdfs/CV_*.pdf` to preserve the website's CV link and older public URLs. Edit a source here, then copy a reviewed PDF to `pdfs/` only when publishing it.
